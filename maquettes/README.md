## Restaurer une version

- **En ligne** : ouvre le lien de la version voulue dans Brave.
- **Hors ligne** : télécharge le fichier `.html` et ouvre-le dans Brave (il lui faut Internet pour charger la 3D).
- **Dans Claude** : demande « reprends la maquette vX » ; une copie de chaque version est aussi rangée dans le Projet « hub », dossier `maquettes/`.
