Active le verrouillage dans Diag. Le hub affiche une clé de secours de 24 caractères, une seule fois : note-la sur papier, hors du PC. Le verrouillage automatique se règle (5, 15, 30, 60 minutes ou jamais). Phrase oubliée : la clé de secours permet d'en choisir une nouvelle.
