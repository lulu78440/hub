---
id: focus
nom: Mode Focus
utilite: Se concentrer 25 ou 50 minutes ; le reste du hub s'estompe.
emplacement: Clic droit sur le fond du hub (ou sur une fenêtre pour la garder nette)
statut_emplacement: provisoire
limites: Le décompte s'arrête si le hub est fermé. Un carillon et une notification signalent la fin.
poste: Atelier
maj: 2026-10-25
mots: focus, concentration, minuteur, pomodoro, travail
---
Clic droit sur le fond, choisis 25 ou 50 minutes. Un anneau orange avec le temps restant tourne autour de l'orbe. Pour garder une fenêtre nette, lance le Focus par un clic droit sur cette fenêtre. Le Noyau peut lancer le Focus pour toi (outil libre).
