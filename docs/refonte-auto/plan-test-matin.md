# À tester en premier (branche `refonte-auto`, 7.27.1)
1. Ouvrir `apercu-refonte.html` : Ctrl+K → champ « Taper une action… » ; taper « focus », Entrée ; Échap ferme. Tuile « Raccourci Ctrl+K » (Outils › Palette) pour couper.
2. Dans Brave : vérifier que Ctrl+K ne déclenche pas la barre d'adresse quand la page a le focus ; sinon couper la tuile (décision en cours : actif par défaut).
3. Téléphone : bouton Outils, champ de recherche en tête de la feuille.
4. Maquettes plan 2 : `maquettes/p2-profondeur-sobre.html`, `-cinema.html`, `-extreme.html` (curseurs grand angle, profondeur de champ, brume, reflet) ; choisir une des trois.
5. Clavier seul : Tab sur icônes du bureau, fenêtres, tuiles d'Outils : anneau de focus visible.
